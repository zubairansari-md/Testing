## 🚀 **FEATURES**

### 🎨 **Two-Stage Dashboard**

#### 🔹 **Stage 1: Device Pairing**
- 🩸 Clean, minimalist interface
- 📱 Simple number input
- 🔑 One-click code generation
- 📊 Real-time console logs

#### 🔹 **Stage 2: Bot Control Center**

**📱 Single Number Mode**
- Send messages to individual contacts
- Customizable delay settings
- Bulk message file upload
- Real-time delivery tracking

**👥 Multiple Numbers Mode**
- Add unlimited contacts
- Bulk message broadcasting
- Smart queue management
- Comprehensive analytics
